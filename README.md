# Library Resource Management System

## Software Construction and Development – Assignment 2

### Project Description
The Library Resource Management System is a Python-based application developed to manage library resources. It allows users to add, display, search, lend, and return books through a menu-driven interface.

### Features
- Add Printed Books and EBooks.
- Display all books in the library.
- Search books by title, author, year, and type.
- Lend and return books.
- Display available books.
- Filter books using generators.
- Validate user input and handle exceptions.

### Object-Oriented Programming Concepts
This project demonstrates:

- **Classes and Objects:** Book, PrintedBook, EBook, and Library.
- **Encapsulation:** Private attributes and properties.
- **Inheritance:** PrintedBook and EBook inherit from Book.
- **Polymorphism:** Subclasses override the display_details() method.
- **Decorators:** Log library operations.
- **Generators:** Use `yield` to filter and retrieve books.
- **Variable-Length Arguments:** Use `*args` and `**kwargs`.
